WHY CHOOSE THIS SUITE

为什么需要这款增强套件？

Antigravity 官方客户端能力出色，但在日常高频高强度开发中，诸多限制影响了流畅度。我们为此构建了开箱即用的终极增强方案。

🌐
❌ 原版痛点：全英文界面，快捷键与复杂设置认知门槛高
✅ 我们的方案：母语级深度全场景汉化，100% 覆盖核心交互

全景原生汉化与零负担使用

深入底层语法树精准注入，全面汉化系统偏好、快捷键面板、微调参数、模型选项及错误状态，绝非粗暴 DOM 替换，原汁原味流畅度。

👥
❌ 原版痛点：单账号限制，配额用尽需手动登出，无法直观掌握余量
✅ 我们的方案：支持多账号功能切换，实时显示账户额度与倒计时

多账号功能切换与实时额度显示

直接在底栏头像呼出切换面板，支持多账号无缝快速切换，并自动向 Google 官方端点并发同步最新剩余额度与重置倒计时，换号前余量一目了然。

🎨
❌ 原版痛点：原生界面布局分散，模型切换步骤多，交互体验不够顺手
✅ 我们的方案：全界面 UI 精致美化，快捷模型切换与悬浮面板一体化

界面 UI 美化与便捷交互体验

做这个套件的核心初衷就是为了让日常交互更方便。重新美化客户端视觉与排版，将模型快速切换与优雅状态感知原生嵌合，让高频操作更加自然顺手。

📊
❌ 原版痛点：上下文 Token 消耗完全是“黑盒”，不可预期何时被截断
✅ 我们的方案：底栏五段式真实上下文 Token 动态遥测胶囊与悬浮窗

上下文预算透明化遥测

精准展示「已缓存、输入载荷、思维推理、回复生成、剩余可用量」，毫秒级反映会话开销，长程开发胸有成竹。

v0.1.5 重磅架构

支持多账号功能切换与实时配额同步

告别外部独立工具的繁琐调用，底栏头像与切换功能彻底合二为一。微光深色毛玻璃悬浮窗让当前状态一目了然。

  • ✔ 快捷多账号功能切换：点击底栏头像一键快速切换不同账号，支持即时搜索与分组标签；
  • ✔ 实时显示账户额度：自动向 Google 端点并发同步最新配额与重置时间，到期自动恢复为 100%；
  • ✔ 本地物理防污染隔离：每组凭证在本地安全目录物理隔离，彻底杜绝串号；
  • ✔ 深度注销二次确认：一键擦除 Windows Credential / Keychain 凭据。

  • ✔ 界面 UI 视觉深度美化：微光圆角卡片、高质感毛玻璃悬浮面板与 ClearType 高清抗锯齿排版；

  • ✔ 实时状态动态感知：底栏彩色胶囊毫秒级遥测上下文，操作反馈更即时；
  • ✔ 独创 DOM 缓存守卫：指纹校验彻底杜绝单页应用死循环卡死与假死。
